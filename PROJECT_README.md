# TeaTime

This project aims to create a web application to simplify recording of data on tea farms.

Using this application, tea farmers are able to easily manage their farms, track collections by tea pickers and process payments.

Tea pickers on the other hand are able to track the collections they made and the resultant payments.

Benefits of this system over physical record-keeping include:

- Neater records
- Better accessibility regardless of location
- Quicker to obtain a summary from the system
- Better protection from tampering
